# Steam Backlog Manager

## Goal

Build a full-stack application that helps Steam users organize and manage their game library.

## Version 1 Features

- User registration and login
- Import Steam library
- Search games
- Filter games
- Mark games as:
    - Backlog
    - Playing
    - Completed
    - Dropped
- Rate games
- Add personal notes
- Random game picker
- Basic statistics dashboard

## Future Features

- Friends
- Recommendations
- Public profiles
- Achievement tracking
